# Open Uniform Evidence Law (OpenUEL)

An open access casebook for students and teachers of evidence law in
Australia's uniform evidence law jurisdictions.

**Read the book:** https://jasonmchin.github.io/OpenUEL/

## About

This casebook is a field stewardship project led by Associate Professor
Jason M Chin (ANU College of Law, Governance and Policy). It aims to
provide a free, high-quality, regularly updated resource covering the
uniform Evidence Acts, for use across Australian law schools.

## Building the book locally

The book is built with [Quarto](https://quarto.org/).

```
quarto preview     # live local preview while editing
quarto render      # build the HTML and PDF versions
```
